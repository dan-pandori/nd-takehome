Let f / [0, 5] -> \mathbb{R} be defined by  f(x):= 1 if * 0 <= x <= 1; 3 if * 1 < x <= 2; 2 if * 2 < x < 3; 4 if * 3 <= x <= 5  Show that f is Riemann Integrable and integrate f = 14 df from 0 to 5 . ## Answer

* To demonstrate that f is Riemann integrable on [0, 5]:  
  - f is bounded on [0, 5], with its range limited to the values {1, 2, 3, 4}.  
  - The function f has discontinuities only at the points x = 1, x = 2, and x = 3, which are isolated points and hence form a set of measure zero in [0, 5].  
  - A function that is bounded on a closed interval and discontinuous on a set of measure zero is Riemann integrable by the Lebesgue criterion.  

* To compute the Riemann integral ∫₀⁵ f(x) dx:  
  - f is a step function with constant values over four intervals: [0, 1], (1, 2], (2, 3), and [3, 5].  
    - Area over [0, 1]: \( 1 \times (1 - 0) = 1 \).  
    - Area over (1, 2]: \( 3 \times (2 - 1) = 3 \).  
    - Area over (2, 3): \( 2 \times (3 - 2) = 2 \).  
    - Area over [3, 5]: \( 4 \times (5 - 3) = 8 \).  
  - Summing these areas gives \( 1 + 3 + 2 + 8 = 14 \).
