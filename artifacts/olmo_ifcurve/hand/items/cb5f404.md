## Prompt (as the model received it)

Let f / [0, 5] -> \mathbb{R} be defined by  f(x):= 1 if * 0 <= x <= 1; 3 if * 1 < x <= 2; 2 if * 2 < x < 3; 4 if * 3 <= x <= 5  Show that f is Riemann Integrable and integrate f = 14 df from 0 to 5 . ## Answer

* To demonstrate f is Riemann integrable:  
  - The function f is bounded on [0, 5].  
    - f takes values in {1, 2, 3, 4}, so it is bounded between 1 and 4.  
  - The set of discontinuities has measure zero.  
    - f is discontinuous only at x = 1, x = 2, and x = 3.  
    - Single points are Lebesgue measurable with measure zero.  

* To compute the integral of f from 0 to 5:  
  - Partition [0, 5] into intervals where f is constant.  
    - On [0, 1], f(x) = 1. Area = (1 - 0) × 1 = 1.  
    - On (1, 2], f(x) = 3. Area = (2 - 1) × 3 = 3.  
    - On (2, 3), f(x) = 2. Area = (3 - 2) × 2 = 2.  
    - On [3, 5], f(x) = 4. Area = (5 - 3) × 4 = 8.  
  - Sum the areas: 1 + 3 + 2 + 8 = 14.
