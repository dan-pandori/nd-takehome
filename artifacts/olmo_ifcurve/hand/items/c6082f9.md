## Prompt (as the model received it)

Let f / [0, 5] -> \mathbb{R} be defined by  f(x):= 1 if * 0 <= x <= 1; 3 if * 1 < x <= 2; 2 if * 2 < x < 3; 4 if * 3 <= x <= 5  Show that f is Riemann Integrable and integrate f = 14 df from 0 to 5 . Your response must include bullet points denoted by * and at least one sub-bullet point denoted by - for each bullet point.

## Verifiable constraints

- `format:sub-bullets` {}: followed (official strict checker)

## Answer

* The function f is Riemann integrable on [0, 5]  
  - It is bounded (all values are 1, 2, 3, or 4) and its discontinuities at x=1, 2, and 3 are isolated points of measure zero  

* The integral of f over [0, 5] is computed by summing contributions from subintervals where f is constant  
  - The intervals [0,1], [1,2], [2,3], and [3,5] yield contributions of \(1 \times 1\), \(3 \times 1\), \(2 \times 1\), and \(4 \times 2\) respectively  
  - Summing these contributions gives \(1 + 3 + 2 + 8 = 14\)
