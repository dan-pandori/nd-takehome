Let f / [0, 5] -> \mathbb{R} be defined by  f(x):= 1 if * 0 <= x <= 1; 3 if * 1 < x <= 2; 2 if * 2 < x < 3; 4 if * 3 <= x <= 5  Show that f is Riemann Integrable and integrate f = 14 df from 0 to 5 . ## Answer

* The function f is Riemann integrable on [0, 5] because it is bounded and its set of discontinuities has measure zero  
  - f is bounded: All function values are integers 1, 2, 3, or 4  
  - The discontinuities occur only at x = 1, 2, and 3, which are isolated points with Lebesgue measure zero  

* The integral of f from 0 to 5 is calculated as follows  
  - Partition the interval [0, 5] into subintervals where f is constant: [0, 1], (1, 2], (2, 3), and [3, 5]  
  - The area of each subinterval contributes: 1 × (1 − 0) = 1, 3 × (2 − 1) = 3, 2 × (3 − 2) = 2, and 4 × (5 − 3) = 8  
  - Summing these contributions gives 1 + 3 + 2 + 8 = 14
