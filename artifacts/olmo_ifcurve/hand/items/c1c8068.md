## Answer

CPD (анализ компонентного разложения) представляет собой обобщение метода PCA, адаптированного для обработки высших порядковых массивов и многомерных данных. Для описания d-режимного тензора 𝒳 ∈ ℝ^{n₁×n₂×…×n_d} он использует формулу в виде линейного сочетания ранговых единичных собраний: 

𝒳 = ∑_{r=1}^R β_r (𝒂_r^{(1)} ⊗ 𝒂_r^{(2)} ⊗ … ⊗ 𝒂_r^{(d)}),  

где R — целое положительное количество компонент (например, 5), β_r — весовые коэффициенты, определяющие significance каждого элемента. Векторы 𝒂_r^{(i)} ∈ ℝ^{n_i} функционируют как factorii i-го режима с единичной нормой: ||𝒂_r^{(i)}||_2 = 1. Understanding их роли: i принимает значения от 1 до d (включая все dimensions), r — от 1 до R (ориентированный на decomposition-модель). Такой подход обеспечивает compact representation сложных структур через удобные для расчетов tensor products. Применение включает data compression, обнаружение patterns и как средство для машинного обучения с массивными входными данными. Основная идея — decompose исходный объект в сочетание rank-1 elements, каждый из которых инвариантен по всем режимам, что даёт природную основу для анализа. Пример: при d=3 (трехмерный массив), каждый component представляет собой число, скаляр β_r, умноженное на трехвектор product 𝒂₁ ⊗ 𝒂₂ ⊗ 𝒂₃. Такая formalization facilitates computation и позволяет разлагать искусственные сети или covariate matrices в их elementary составляющие. Нормировка векторов гарантирует numerical stability, а parameter R управляет trade-off между точностью и model complexity.
