## Answer

* The function f is Riemann integrable on [0,5]  
  - It is bounded, with values restricted to {1, 2, 3, 4}  
  - Discontinuities occur only at x=1, x=2, and x=3 (jump discontinuities), which form a set of measure zero  

* The integral of f from 0 to 5 is 14  
  - The interval [0,5] is divided into subintervals where f is constant: [0,1], (1,2], (2,3), [3,5]  
  - The contribution of each subinterval is calculated and summed: (1×1) + (3×1) + (2×1) + (4×2) = 1 + 3 + 2 + 8 = 14
