**Proof that a Step Function on \([a, b]\) is Riemann Integrable:**  

A **step function** \( f: [a, b] \to \mathbb{R} \) is defined as a function that is constant on a finite number of subintervals partitioning \([a, b]\). Specifically, there exist points \( a = x_0 < x_1 < \cdots < x_n = b \) such that \( f \) is constant \( c_k \) on each subinterval \([x_k, x_{k+1})\) (or \([x_k, x_{k+1}]\), depending on partitioning).  

### Key Steps of the Proof:  
1. **Boundedness:**  
   Since \( f \) is piecewise constant with a finite number of intervals, it is bounded on \([a, b]\). Let \( M = \max\{ |c_0|, |c_1|, \ldots, |c_n| \} \). Then \( |f(x)| \leq M \) for all \( x \in [a, b] \).

2. **Discontinuities are Finite:**  
   A step function is continuous on each open subinterval \((x_k, x_{k+1})\). The only potential discontinuities occur at the partition points \( x_1, x_2, \ldots, x_{n-1} \), which are **finitely many**. A finite set has Lebesgue measure zero, satisfying the **Lebesgue criterion** for Riemann integrability (a bounded function with discontinuities on a set of measure zero is Riemann integrable).

3. **Direct Construction of Upper/Lower Sums:**  
   Let \( P = \{x_0, x_1, \ldots, x_n\} \) be the partition aligned with the step points. For this partition:  
   - On each subinterval \([x_k, x_{k+1}]\), \( f \) is constant \( c_k \).  
   - The **upper sum** \( U(f, P) = \sum_{k=0}^{n-1} c_k (x_{k+1} - x_k) \).  
   - The **lower sum** \( L(f, P) = \sum_{k=0}^{n-1} c_k (x_{k+1} - x_k) \).  
   - Thus, \( U(f, P) = L(f, P) \), so their difference is zero.  

   For any \( \epsilon > 0 \), choose \( P \) as above. Since \( U(f, P) - L(f, P) = 0 < \epsilon \), the function satisfies the Riemann integrability condition.  

### Conclusion:  
A step function \( f \) is **Riemann integrable** on \([a, b]\) because it is bounded, its discontinuities form a set of measure zero, and its upper and lower sums coincide for a suitable partition.  

$\boxed{\text{A step function on }[a, b]\text{ is Riemann integrable.}}$
