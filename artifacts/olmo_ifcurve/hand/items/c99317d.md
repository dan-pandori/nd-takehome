## Answer

To extract filenames from file paths in Python, use **`os.path.basename`** or **`pathlib.Path.name`**. Both handle cross-platform paths automatically.

### Method 1: Using `os.path.basename()`
```python
import os
filepath = "/path/to/your/file.txt"
filename = os.path.basename(filepath)
```
Output: `"file.txt"`

### Method 2: Using `pathlib.Path.name`
```python
from pathlib import Path
filepath = "C:\\Users\\User\\file.docx"
path = Path(filepath)
filename = path.name
```
Output: `"file.docx"`

### Edge Cases
- **Trailing separators:**  
  If `filepath` ends with `/` or `\`, `basename`/`name` returns an empty string. Ensure paths do not end with these unless directory-only access is required.  
- **Windows/Unix paths:** Both methods abstract OS-specific separators (`/` vs `\`).

### Key Notes
- `os.path.basename` returns the **full filename** (including extension).  
- `pathlib.Path.name` does the same, with additional capabilities like path validation.  

Choose either method based on preference or compatibility needs.
