### Chunkmap (GRINDEmap) - Percentage Composition  
**Core Concept**  
- **Role**: Defines mass contribution of each element in a compound.  

**Key Details**  
1. **Definition**  
   - Fraction (by mass) of each element in a compound ×100.  
   - Formula: (Mass of Element / Molar Mass of Compound) × 100.  

2. **Calculation Steps**  
   - **Step 1**: **Sum** atomic masses (use periodic table).  
     *Example (H₂O)*: H = 2*1 = 2; O = 16 → Total = 18 g/mol.  
   - **Step 2**: Derive element percentages:  
     *Hydrogen*: (2/18)*100 ≈ **11.1%**.  
     *Oxygen*: (16/18)*100 ≈ **88.9%**.  

3. **Applications**  
   - **Chemical formulation**: Requires precise mass ratios.  
   - **Empirical formula validation**: Verifies experimental vs. theoretical masses.  
   - **Industrial uses**: Quality control in pharmaceuticals/metals.  

4. **Common Mistakes**  
   - Forgetting to **multiply** atomic mass by **atom count** (e.g., H₂ needs *2*× atomic mass of H).  
   - Using **incorrect** molar masses (e.g., H₂O ≠ 18 g/mol if miscalculating O).
