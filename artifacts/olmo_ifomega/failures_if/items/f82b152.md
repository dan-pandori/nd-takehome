Power law scaling in neural networks indeed suggests that performance gains diminish as training data increases. Specifically, improvements often follow a sublinear relationship—meaning doubling data yields progressively smaller performance boosts. For instance, if performance ~ (data)^β with β < 1, a fixed percentage gain in accuracy demands exponentially rising data volumes. Say Β is 0.3: achieving a 10% performance rise requires (1.1)^(1/0.3) ≈ **37% more data**, while a mere 1% improvement still needs ~5% additional data. Though not *mathematically* exponential (which multiplies by a constant base per step), the trend reflects **rapidly escalating data requirements for modest progress**, akin to an exponential curve in colloquial terms. Thus, sustaining gains hinges on vast, impractical data scopes unless paired with model scaling or architectural innovations.
