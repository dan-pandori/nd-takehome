* The function f is Riemann integrable on [0, 5] because it is bounded and its discontinuities form a set of measure zero.  
  - f is bounded between 1 and 4 over the entire interval, as its constant values only take the discrete values 1, 2, 3, and 4.  
  - The discontinuities occur only at isolated points (x = 1, 2, and 3), and a finite set of points has Lebesgue measure zero, satisfying the Riemann integrability criteria.  

* The integral of f from 0 to 5 is computed by summing the areas of the rectangles over each interval where f is constant.  
  - The interval [0, 1] contributes \(1 \times 1 = 1\).  
  - The interval (1, 2] contributes \(3 \times 1 = 3\).  
  - The interval (2, 3) contributes \(2 \times 1 = 2\).  
  - The interval [3, 5] contributes \(4 \times 2 = 8\).  
  - Summing these areas gives \(1 + 3 + 2 + 8 = 14\), so \(\int_{0}^{5} f(x) \, dx = 14\).
