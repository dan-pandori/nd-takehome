**Status legend**
- **reviewed-stands**: an independent reviewer re-derived it from the raw files, and it reproduces with its wording.
- **reviewed-corrected**: a review, or one of this run's checks, found the number, its label or its wording wrong. This
  run's checks are the v1 re-check, the ledger critic and this v2.
  - Use the **bold** value after →, never the original.
  - "(label)" / "(wording)" means the number reproduces but must be stated differently.
  - A correction made by this run is itself unreviewed and says so.
- **contradicted**: a later file contradicts it. Use it only to report the correction.
- **unreviewed**: no independent recount, e.g. an executor-only file of an earlier run or this ledger's own arithmetic on
  inherited files. Not for a headline until checked.
- **this run (unreviewed)**: computed by `create-or-elicit` itself (executor, its sub-agents, the ledger critic or this
  ledger) and not yet reviewed by anyone independent. Not for a headline until checked.
- **verified quote (V)** (literature rows only): the lit review's claim ledger found the quote verbatim at the stated
  location. This checks the citation, not the paper's correctness.
